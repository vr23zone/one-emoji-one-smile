# One Emoji, One Smile

A tiny program for the make.fun bounty "One Emoji, One Smile".

Running `main.ts` (Node 22) writes exactly one emoji to
`/output/entry.txt`, followed by a single trailing newline,
and exits with code 0. No arguments, no input, no network.

The emoji it writes is:

🫶

That is U+1FAF6 HEART HANDS — one character, 4 bytes in UTF-8.
